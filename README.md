# 🟦 НАЧАЛО ПРОМПТА — `docs/SPEC.md`

## 0. Роль и миссия

Ты — ведущий разработчик и геймдизайнер проекта **KAPITALIA**. Доведи игру до **полной версии** по этой спецификации: серверная экономика, тик-движок, мобильный клиент Godot 4, веб-клиент, админка, тесты, баланс, релиз. Спецификация — источник истины по механикам; `design/DESIGN.mobile.md` — по визуалу; `balance.json` — по числам. Существующие сцены M0–M9, `navigation_controller.gd`, `kapitalia_theme.tres` — дорабатывать, не переписывать.

## 1. Продукт

* **Название:** КАПИТАЛИЯ / KAPITALIA. **Слоган:** «Семь пересчётов в день. Одна империя на всех».
* **Жанр:** tick-based MMO economic strategy / бизнес-тренажёр.
* **Платформы:** Godot 4 (Android/iOS, portrait) + веб (desktop-first, адаптив) на одном API.
* **Аудитория:** 18–45, экономические стратегии, студенты, предприниматели. Сессия 5–15 мин, 2–5 раз в день.
* **Модель:** F2P, строго без pay-to-win.
* **Язык:** RU/EN, всё через ключи локализации.

## 2. Мир и время

* Континент **Меридиан**: 3 страны (Нордия, Солария, Ферратия), **24 города**, у каждого: население 120k–3M, уровень 1–5, индекс достатка, средняя зарплата, индекс аренды, ставка налога, безработица, инфраструктура (дороги/школы/больницы/порт), отраслевая специализация.
* **Время:** 1 реальный день = 1 игровая неделя. **7 тиков/сутки** (МСК): 10, 13, 16, 19, 22, 01 — дневные; **04:00 — недельный** (финансовый итог).
* Приказы фиксируются снапшотом до тика; за 60 сек — блокировка. Мир живёт при офлайне игрока по политикам автопилота.
* Валюты: базовая **CR** + 3 национальные с плавающим курсом от торгового баланса.

## 3. Компания и прогрессия

* Старт: **5 000 000 CR**, 1 предприятие, стартовый город.
* Уровни компании 1–30; лимит предприятий `2 + floor(level * 1.4)`; опыт за оборот, прибыль, освоение отраслей.
* **Очки квалификации** по 8 отраслям: добыча, производство, торговля, логистика, финансы, медиа, наука, строительство.
* **8 специализаций** (выбор 2, смена раз в сезон): вертикальный холдинг, торговый дом, технологический лидер, логистический оператор, медиамагнат, девелопер, финансист, агропромышленник.
* Холдинги: дочерние компании, управляющая компания, внутригрупповые трансферы по трансфертным ценам (с проверкой на нерыночность).
* Банкротство: реструктуризация с потерей 30% активов, кредитная история, запрет IPO на 2 сезона.

## 4. Предприятия

**12 типов, 44 подтипа:** магазин (6 форматов), склад (3), офис (3), завод (10 профилей), шахта (4), ферма (5), животноводческая ферма (3), стройка (2), недвижимость (2), СМИ (4), лаборатория (2), логистический терминал (2).

* Уровни 1–10; апгрейд `cost(n) = base_cost * 1.9^(n-1)`, длительность 2–6 тиков.
* Подразделения: цеха, закупки, продажи, HR, R&D, маркетинг — слоты персонала + менеджер.
* Ёмкость: `capacity = base_capacity(n) * equipment_factor * staff_efficiency`.
* Оборудование: 5 классов, производительность, износ **0.8–2.5%/игровой день**, ремонт, модернизация, амортизация, вторичный рынок.
* Продажа предприятия: английский аукцион 24 реальных часа, шаг 5%.

## 5. Товары и цепочки

* **200 SKU**, 12 категорий: продукты, напитки, одежда, бытовая химия, электроника, мебель, стройматериалы, топливо, лекарства, транспорт, услуги, медиа-продукты.
* **120 рецептур (BOM)**, 3–5 переделов. Примеры цепочек: руда→сталь→детали→техника; нефть→пластик→упаковка; зерно→мука→хлеб; лес→доски→мебель; хлопок→ткань→одежда; песок→стекло→бутылки; литий→батареи; кремний→чипы→электроника.
* Качество 0–100 (в UI — уровни 1–10), эталонное качество по категории и городу.
* Скоропортящиеся товары: срок годности в тиках, порча, холодильные склады, уценка.
* Хранение: стоимость за тонну-тик, лимиты ёмкости, страховка запаса.

## 6. Экономика — формулы

```
demand_pool = population * consumption_rate(cat) * wealth_factor * season * macro
attract     = q_norm^1.6 * p_norm^-2.2 * brand^0.35 * marketing^0.25 * service
share_i     = attract_i / Σ attract
sales_i     = min(stock_i, demand_pool * share_i)
p_norm      = clamp(price / reference_price, 0.4, 3.0)
q_norm      = clamp(quality / reference_quality, 0.2, 3.0)

quality     = Σ(material_quality_j * influence_j) + (1 - Σinfluence_j) * tech_max_quality
quality    *= department_efficiency                      // 0.55..1.15
eff         = clamp(staffing * (0.6 + 0.4*skill) * wage_factor * equipment * manager, 0.3, 1.6)
wage_factor = clamp(0.7 + 0.5 * (salary / city_market_wage), 0.7, 1.25)

brand_next  = brand * 0.94 + 0.06 * (ad_reach * ad_quality)      // затухание без рекламы
ad_reach    = Σ(media_audience_k * slot_share_k) * targeting_fit
logistics_cost = tons * distance * tariff(transport) * (1 + fuel_index)
delivery_ticks = ceil(distance / speed(transport, roads_level))
spoilage    = stock * max(0, (age - shelf_life) / shelf_life) * 0.15
unit_cost   = moving_weighted_average(lots) + weekly_overhead_allocation
```

* Себестоимость — средневзвешенная по партиям; в недельный тик входят зарплата, аренда, амортизация, общезаводские, проценты.
* B2B-приоритет: прямой контракт → биржа → спот. Автопилот: «запас X дней, макс. цена Y, качество не ниже Z».
* macro: инфляция от денежной массы, курсы от торгового баланса, безработица от найма, миграция в города с высокими зарплатами и жильём.

## 7. Рынки

* **Товарная биржа:** лимитные/рыночные заявки, price-time priority, стакан, глубина, спред, история свечей, circuit breaker ±20% за тик.
* **Контракты:** объём/тик, цена (фикс/формула/индекс), качество-пол, длительность, неустойка, эскроу.
* **Тендеры:** закрытые, оценка по цене/качеству/рейтингу/сроку; государственные тендеры мэрии.
* **Аукционы:** предприятия, оборудование, лицензии, недвижимость.
* **Валютный рынок:** обмен по курсу + спред, форвардные контракты.
* **Фьючерсы:** на 6 базовых товаров, гарантийное обеспечение, экспирация в недельный тик, маржин-колл.
* **Страхование:** запасы, оборудование, грузы, кредитные дефолты; премия от риск-профиля.

## 8. Финансы

* Двойная запись `finance_ledger`, никаких прямых UPDATE балансов.
* Отчёты: P&L, баланс, ДДС, себестоимость по SKU, маржинальность по предприятиям, сравнение недель.
* Налоги: прибыль 12–25% по региону, НДС в рознице, налог на имущество, льготы от инфраструктуры.
* Кредиты: ставка 1.5–4%/игровую неделю, лимит `3 × недельная выручка` + залог, кредитный рейтинг, овердрафт со штрафом.
* Облигации: выпуск купонных бумаг, вторичный рынок, дефолт и реструктуризация.
* Депозиты, эскроу, внутригрупповые займы, дивидендная политика.

## 9. Корпорации и фондовый рынок

* Уровень компании 12+ → корпорация: IPO (проспект, андеррайтер, эмиссия ≤ 49%), free-float.
* Матчинг заявок, tick size, индексы (KAP-30, отраслевые), дивиденды из чистой прибыли, buyback, сплиты.
* Совет директоров: голосование акциями, стратегии, одобрение крупных сделок, враждебные поглощения.
* Раскрытие: публичная отчётность корпораций, инсайдерские ограничения для директоров.

## 10. Наука и технологии

* Лаборатории генерируют RP; **60 узлов** дерева, 4 ветки: качество, объём, себестоимость, экология.
* Доступ по уровню предприятия: ур.2 → 1 тип, ур.5 → все 4.
* Патенты: срок эксклюзива в игровых неделях, лицензии с роялти, продажа технологий, промышленный шпионаж (риск штрафа).

## 11. Персонал и менеджмент

* Городской пул труда по квалификации 1–10, безработица, эластичность найма к зарплате.
* Обучение: стоит денег и тиков, +квалификация; учебные центры как отдельный бизнес.
* Текучка при зарплате ниже рынка; профсоюзы и забастовки при prolonged недоплате.
* Менеджеры: 6 характеристик (лидерство, аналитика, переговоры, отраслевой опыт, стрессоустойчивость, лояльность), опыт, контракты с неустойкой, хантинг у других игроков.

## 12. Государство и города

* Мэры: выборы каждые 4 игровые недели, голос = f(уровень компании, рабочие места в городе).
* Мэр в пределах лимитов задаёт: ставку налога, приоритет инфраструктуры, городские тендеры.
* Инфраструктура: дороги → скорость логистики; школы → квалификация; больницы → рост населения; порт → международная торговля.
* Законы страны: торговые пошлины, экологические штрафы, субсидии отраслям.
* Международная торговля: пошлины, квоты, торговые соглашения между странами.

## 13. Социальный слой

Альянсы/картели (общая казна, контракты, роли), чаты (альянс/город/отрасль/торговля), почта с вложениями контрактов, менторство новичков (бонус обеим сторонам), публичные рейтинги (капитализация, прибыль, оборот, отраслевые, мэры), сезонные турниры, доска банкротов, репутационный скоринг контрагентов.

## 23. Sim, баланс, нагрузка

`sim-harness`: 1000+ ботов, 5+ стратегий (демпинг, премиум-качество, вертикальная интеграция, спекулянт, автопилот, девелопер, финансист), прогон 30 игровых недель.

**Гейты:** детерминизм (идентичный checksum) · ни одна стратегия не даёт > 2.5× медианной доходности · инфляция ≤ 35%/сезон · неудовлетворённый спрос 10–30% · банкротства ≤ 15% · Gini ≤ 0.65 · новичок до первой прибыли ≤ 20 мин · покрытие ядра ≥ 80%, API ≥ 60% · ноль дюп-эксплойтов · нагрузка 50k компаний проходит.

## 24. Безопасность, анти-чит, юридика

Детект мультиаккаунтов (fingerprint + граф переводов + поведение), лимиты безвозмездных переводов, флаг нерыночных цен, аудит всех сделок, теневые ограничения вместо мгновенного бана, апелляции, панель модератора, полный `audit_log`, запрет RMT. Виртуальные ценности не выводятся в деньги; 16+, оферта, 152-ФЗ/GDPR, экспорт и удаление данных. Весь контент и нейминг оригинальные.

## 27. Правила работы агента

Одна фаза = один цикл: план → код → тесты → субагент reviewer → фиксы critical/high → `docs/reports/phase-N.md` → коммит `phase-N: ...`. Не более 3 уточняющих вопросов за фазу; остальное решать самому и писать в `DECISIONS.md`. Никаких TODO/заглушек в доменном ядре. Каждая формула — unit-тест с числовым примером. Эксплойт дюпа: сначала воспроизводящий тест, потом фикс. Числа — только в `balance.json`. Не трогать `design/`, не делать `git push` без команды. Отчёты по-русски.
